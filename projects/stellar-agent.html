Stellar-Agent

IaC-Rule Set & MCP 기반 정책 감사 도구

IaC 보안 감사의 비효율성과 부정확성을 줄이기 위해 만든 하이브리드 DevSecOps 프레임워크입니다. 룰셋 기반 스캐너의 넓은 탐지 범위와 AI 에이전트의 맥락 분석을 결합했습니다.

  • 문제 — 정적 분석(SAST) 도구는 런타임 컨텍스트가 없어 오탐이 많고, 수동 감사는 반복 검증에 따른 피로와 대규모 인프라에서의 확장성 부재라는 한계가 있었습니다.
  • 접근 — Checkov·KICS·Trivy 등 룰셋 기반 스캐너로 넓게 훑고, AI 에이전트가 그 결과를 맥락에 맞춰 다시 판단하는 2단 구조로 설계했습니다.
  • 구조 — JSON-RPC 기반 모델 컨텍스트 프로토콜(MCP)을 에이전트 제어 평면(Agentic Control Plane)으로 두고, AI가 여러 스캐닝 도구와 지식 베이스를 직접 오케스트레이션하도록 했습니다.
  • 지식 참조 — RAG 엔진으로 CVE 정보와 조직 내부 컴플라이언스 정책을 참조해, 위험 영향도와 우선순위를 붙인 수정 권고안을 만들도록 설계했습니다.
  • 담당 — 팀에서 IaC 파트를 맡아, IaC 파일을 SBOM으로 바꾸는 도구의 CloudFormation 파서(문법 검증, !Ref·!GetAtt·!Sub 태그 처리, Parameters·Mappings·Conditions 변수 추출)를 구현했고 스캐너 연동 일부에 참여했습니다. 학술대회 논문에는 공저자로 이름을 올렸습니다.
