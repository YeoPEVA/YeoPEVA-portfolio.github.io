화이트햇 콘테스트 2025 예선 — 풀이 발췌 정정 노트

작성 2026.10.06 · 이창엽 · 대상: 뒤에 붙인 2–8쪽 (대회 당시 제출한 결과보고서 중 본인 풀이 2문제의 발췌)

뒤의 7쪽은 대회 당시 팀이 제출한 결과보고서에서 본인이 푼 두 문제(문제 4 시나리오 1-3, 문제 7 Leakage Investigation)를 발췌한 것으로, 내용을 고치지 않고 그대로 두었습니다. 이후 검토에서 확인한 오류와 근거보다 강하게 쓴 결론을 아래에 정리합니다. 쪽 번호는 이 파일 기준입니다.

#쪽당시 서술정정
14쪽 ngx_http_secure_link_module이 “보안과 관련된 여러 HTTP 헤더를 자동으로 추가”하고 기본 빌드가 아니라는 점을 들어 백도어라고 확신 이 모듈은 요청 링크의 진위·접근 조건·유효기간을 검사하는 모듈입니다. 같은 쪽에 실린 nginx 공식 문서 화면도 그렇게 설명합니다. 기본 빌드에 들어가지 않는 것은 정상 선택 모듈에도 해당하므로 악성의 근거가 아니며, 의심 파일 secure_headers와는 이름도 다른 모듈입니다.
23–4쪽 파일 크기·수정 시각과 위 조사를 근거로 “공격자가 설치한 백도어 파일”로 결론 근거는 GET /bd 접근 기록, 파일 크기·수정 시각, strings 등으로 본 모듈 내부 정보로 좁힌 후보 식별입니다. 제출한 경로(답안)는 정답으로 인정됐지만, 모듈 코드와 실행 동작은 분석하지 않아 백도어 기능 자체를 입증한 것은 아닙니다.
33쪽 수정 시간대 “10-09 오후 6시 15분” FTK Imager 표시 시각의 시간대를 확인하지 않았습니다. 접근 로그는 +0000(UTC) 기준이므로 두 시각을 비교하려면 시간대를 맞춰야 하며, 이 자료만으로는 두 사건을 연결할 수 없습니다.
45쪽 198.51.100.23이 예약된 특수 IP 대역이라 “유출에 활용된 패킷들이라고 판단” 198.51.100.0/24는 문서·예제용 예약 대역(RFC 5737)입니다. 대회 데이터에서 조사 대상을 고르는 단서일 뿐 유출을 입증하지 않습니다. 유출로 본 근거는 이후 확인한 대화(6–7쪽)와 이미지 복원 결과(8쪽)입니다.

고치지 않은 것 — 증거 화면, 제출한 답안(플래그), 풀이 순서. 3쪽의 “IP 정보가 다르다”는 출발지 IP가 다르다는 뜻으로 원문 표현이 맞습니다(다른 요청 10.1.0.216·10.1.0.250, /bd 요청 10.1.0.121).
